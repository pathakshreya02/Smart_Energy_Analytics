# Smart Energy Analytics

## Overview

This project predicts daily household energy consumption using smart meter data and weather information.

## Dataset

London Smart Meter Dataset

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Workflow

- Data Cleaning
- Feature Engineering
- Exploratory Data Analysis
- Machine Learning
- Model Evaluation

## Models

- Linear Regression
- Decision Tree
- Random Forest

## Evaluation Metrics

- MAE
- RMSE
- R² Score

## Output

Predicts daily electricity consumption.
