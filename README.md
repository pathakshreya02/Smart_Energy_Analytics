# Smart Energy Analytics

## Project Overview

This project predicts household electricity consumption using machine learning and the London Smart Meter Dataset.

## Features

- Data Cleaning
- Feature Engineering
- Exploratory Data Analysis (EDA)
- Correlation Heatmap
- Weather Data Integration
- Household Information Integration
- Holiday Analysis
- Random Forest Regression
- Model Evaluation

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset

London Smart Meter Dataset (not included due to GitHub file size limits).

## Machine Learning Model

Random Forest Regressor

## Evaluation Metrics

- MAE
- RMSE
- R² Score
